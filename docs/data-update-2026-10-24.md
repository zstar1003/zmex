# 2026-10-24 招生数据更新审计

## 解析与核验

### 河北

一分一段原件为 18 页扫描 PDF，没有文字层。先按表格格线提取、抑制红色水印，再识别数字。逐档检查分数连续性、人数和累计人数关系；29 处 OCR 差异均查看原始 PDF 对应行后更正，未用差值反推替代原图核验。

`data/admissions/extracted/hebei-2026-score-ranks-audit.json` 保存五列完整数据、原页码、OCR 前后值及原 PDF SHA-256。共 562 档，覆盖表内 701 至 140 分，140 分档累计人数为物理 350,991、历史 231,476。物理“701 及以上”和历史“671 及以上”为原表合并档，仅采用该档公布的累计人数上限，不补造高分考生精确位次。

原 PDF SHA-256：`fcd70c8356b95dc787b92c1c1f7c97183fc5a1532dadf492714e3d5edae7cf16`。

抽查结果（物理 / 历史累计人数）：600 分 29,425 / 5,931；555 分 77,185 / 21,417；500 分 158,553 / 53,690；470 分 202,675 / 74,795。

### 辽宁

位次 PDF 有文字层，按字体和列坐标排除斜向水印，提取分数、人数、累计人数。物理 558 档、历史 518 档，逐档校验人数差分与累计人数。沿用原表的稀疏高分档，不为未公布档位补造排名。解析脚本新增 `--year 2026`，默认 2025 行为保留。

### 湖北

专业组 PDF 按表格提取组代码、名称、选科要求、投档最低分和备注；原表 27 个空白分数行不作为零分导入。普通组导入遵循备注资格过滤，原始提取结果保留页码和单元格。历史科目位次表没有 672 分档，也没有覆盖该分数的合并档，因此未导入清华大学 `A00305` 这一行，不为其补造位次。专业组最低分对应 2026 年一分一段表的累计人数，不能解释为组内每个专业的录取位次。

一分一段原图的解析过程、各图哈希、人工核图更正和分档校验记录保存在 `data/admissions/updates/hubei-2026-group-sources.json` 及对应参考表。华北水利水电大学的 14 条记录直接采用高校公布的专业最低位次，未用专业组门槛替代。

## 数据使用边界

- 本轮新增官方分数换算记录均配套同年参考表。山东源表仅有最低位次，规范化记录的 `minScore` 为 `null`，不借用其他年份的分数填空。
- 排名查询在招生省份、院校和科类范围内按专业名称选最新年份，同年优先官方来源；历史数据继续保存，尚无新记录的专业仍使用其真实旧年份。专业名称改变、组编号改变不能自动视为同一条历史记录。
- 关键词筛选只能匹配已有专业或专业组名称。湖北专业组源表没有组内专业清单，输入“电气”不会凭空查出组内未公布的电气专业；已有具体专业记录则可正常匹配。
- 本轮没有完成其他省份的 2026 年全量更新。重庆官方站及附件未能可靠获取，保留已核验的 2025 年数据；不能据此断言官方尚未发布 2026 年结果。
- 既有掌上高考记录主要是 2025 年，旧 README 中“其余多数省份为 2024 年”的描述已纠正。保留记录仍包括不同年份，不统一改标为最新年份。
- 新疆既有 365 条记录把 2025 年最低分与 2024 年转载一分一段表对应；西藏既有 736 条 2025 年记录采用基于 2024 年考生规模、招生计划和控制线的粗略位次模型。这是本轮之前就存在的局限，本轮未新增此类跨年换算或估算记录，不能把全部历史记录表述为同年官方位次。
- 原始表中的未匹配院校、缺失有效位次、缺失最低分等记录会按解析规则排除；来源的原始行数、导入行数和排除数量应一并核对。

## 复现及更新流程

在已保存本轮原始附件和审计提取结果的仓库中，可以复验位次参考表：

```bash
python3 scripts/parse-hebei-ranks.py
python3 scripts/parse-liaoning-ranks.py --year 2026
python3 scripts/parse-hubei-2026-sources.py
```

河北命令验证已人工核对的提取审计、原 PDF 哈希和全部累计关系后重建参考表，不重新执行 OCR。辽宁需要 `pdfplumber`；湖北需要 `pdfplumber`、`opencv-python`、`numpy` 和 Tesseract，可用 `--only groups` 或 `--only ranks` 分别重建。

先在暂存目录生成官方规范化数据和全国索引：

```bash
bun run sync:admissions --output-dir=/tmp/zmex-admissions-2026
```

该目录包含 `provinces/`、`index.json` 和 `coverage.json`；来源清单、已保存的提取结果和原始缓存仍从仓库读取。`--province=河北省` 等参数可以限定单省，脚本保留其他省份的索引条目。`--refresh` 用于重新下载；如原始文件内容变化，先复核或重建相应提取结果，不跳过哈希校验。

掌上高考同步必须显式选择年份，不再默认为旧年份：

```bash
bun run sync:aggregated --year=2026 --province=湖北省 --output-dir=/tmp/zmex-aggregated-2026
```

聚合同步会校验请求年份、源记录年份和换算参考表年份；不会复用其他年份缓存，也不会用旧年份覆盖新年份。请求失败、零条有效结果或比原数据减少超过 20% 时拒绝替换原数据。`--allow-record-drop` 仅用于人工确认实际覆盖下降后的重新运行，不绕过请求失败、零行和年份检查。官方同步也拒绝年份不一致、原件哈希与提取结果不一致、零条有效记录或不符合已登记预期数量的输入。

暂存结果核验后再生成正式目录，并重建专业详情索引、执行测试和全国数据校验：

```bash
bun run sync:admissions
bun run build:major-index
bun run test
bun run verify:admissions
```

`verify:admissions` 当前读取仓库正式目录。暂存阶段先比较清单、各源行数及代表性专业，正式重建后再运行完整校验；暂存命令本身不代表站点已发布，也不代表线上部署完成。

## 验证结果

- 43 项自动测试全部通过，全国 565,446 条记录通过来源、重复 ID、位次及数量校验；专业详情索引重建为 209,066 条。
- 浏览器实测湖北物理类第 80,000 位、院校限定湖北：787 条结果跨 16 页保持分数降序，首条 528 分、末条 426 分；“电气”筛选为 13 条。
- 浏览器下载的 Excel 回读分别为 787 行与 13 行，与网页排序及筛选一致；打印页面包含全部 13 条筛选结果并可生成 PDF。
- 河北历史第 1 位查询中，清华大学 2026 年 684 分记录保留，显示“官方合并档位次上限 31 名”及合并档来源说明。
- 390 像素宽移动页面没有横向溢出，1440 像素桌面布局及 PDF 输出经过查看。
