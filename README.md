# 择木而栖 ZMEX

面向高考志愿筛选的静态可视化网站，提供全国院校分布地图、专业录取位次参考和专业倾向测评。站点优先使用可追溯的公开数据，无法取得完整官方专业线时会明确标注数据边界。

线上站点：https://zmex.zstar.website/

## 功能

- 全国院校地图：覆盖教育部《全国普通高等学校名单》中的普通本科院校和高职（专科）院校。
- 院校筛选：支持按省份、办学层次、本科/专科、办学性质、重点标签和院校类型筛选。
- 排名估算：按“省份 + 科类 + 全省排名”查询可参考专业，并支持限定院校所在省份。
- 结果排序：所有匹配专业按最低分降序排列，同分按位次升序，缺失分数排在最后；分页不会重新打乱顺序。
- 结果内专业筛选：查询后在左侧输入“电气”等关键词，实时筛选全部查询结果中的专业名称；清空关键词可还原结果。
- 结果导出：支持将筛选后的全部结果导出为 Excel（`.xlsx`），或打开打印页面选择“另存为 PDF”，包含查询条件和数据来源，不受当前分页限制。
- 专业详情：点击院校或专业后展示专业排名参考、已整理的专业录取位次和原始来源入口。
- 专业倾向测评：提供轻量的兴趣倾向问卷，辅助缩小专业方向。

## 运行

本项目使用 Bun。

```bash
bun install
bun run start
```

打开 `http://localhost:5173/`。

回归验证：

```bash
bun run test
bun run verify:admissions
```

Excel 导出使用随仓库提供的本地 SheetJS 浏览器模块，无需访问 CDN。更新现有 `xlsx` 依赖后，可运行 `bun run vendor:xlsx` 重新复制模块和许可证。

## 数据

主院校数据来自教育部《全国普通高等学校名单》（名单截至 2025-06-20，公告发布于 2025-06-27）。当前生成结果：

- 普通高校总数：2919 所
- 本科院校：1365 所
- 高职（专科）院校：1554 所
- 覆盖省级地区：31 个
- 覆盖城市：347 个

核心数据文件：

- `data/schools.json`：前端主院校数据，含本科和专科。
- `data/china.json`：中国地图 GeoJSON。
- `data/raw/moe-colleges-2025.xls`：教育部原始附件。
- `data/raw/moe-colleges-2025.rows.json`：由 Excel 转出的二维数组。
- `data/admissions/sources.json`：各省投档数据源登记表。
- `data/admissions/provinces/`：已取得官方专业或专业组投档线省份的规范化数据。
- `data/admissions/aggregated/provinces/`：公开专业录取数据与来源索引。
- `data/admissions/reference/`：一分一段表的结构化记录，注明年份和位次定义。
- `data/admissions/extracted/`：PDF、网页的提取结果及人工核对记录。
- `data/admissions/updates/`：本轮新增来源、原始附件地址及核验信息。
- `scripts/build-data.mjs`：生成院校地图数据。
- `scripts/sync-admissions.mjs`：下载、校验并规范化官方投档数据。
- `scripts/sync-gaokao-cn.mjs`：逐省逐校查询公开专业录取数据。
- `scripts/verify-admissions.mjs`：校验全国记录数量、来源、重复 ID 和位次字段。

重新生成院校数据：

```bash
bun run build:data
```

同步已登记的官方投档表时，先生成到暂存目录，检查来源和数量后再更新站点数据：

```bash
bun run sync:admissions --output-dir=/tmp/zmex-admissions-2026
```

查询掌上高考公开专业录取数据必须明确指定年份。例如，单独核验湖北 2026 年数据：

```bash
bun run sync:aggregated --year=2026 --province=湖北省 --output-dir=/tmp/zmex-aggregated-2026
```

这些命令不会因为 2026 年数据缺失而自动把 2025 年记录改标为 2026 年。聚合数据同步遇到请求失败、零条有效结果、记录数减少超过 20% 或年份回退时会拒绝覆盖；位次换算只使用与本次录取数据同年的参考表。正式数据更新后重建专业索引并验证：

```bash
bun run build:major-index
bun run test
bun run verify:admissions
```

## 位次数据规则

截至本轮 2026-10-24 核验，已整理浙江、山东、河北、辽宁的 2026 年官方专业投档表，以及湖北的 2026 年官方院校专业组投档线和华北水利水电大学在湖北的 14 条实际专业录取记录。新增 93,281 条 2026 年记录，保留此前 472,165 条历史记录，全国索引共 565,446 条。各省覆盖、原始来源和核验方法见[数据更新审计](docs/data-update-2026-10-24.md)。这不表示全国所有省份、院校和批次都已更新至 2026 年。

排名查询按招生省份、院校和科类筛选，同一专业名称优先使用最新年份；同年优先使用官方来源。旧年份记录保留作为历史资料，尚无新年份数据的专业仍会显示其实际年份。专业改名或专业组编号变化不会自动认定为同一专业。

- 浙江、山东的官方表直接提供位次。山东本轮表没有最低分列，`minScore` 保持为空，不从其他年份补分数。
- 河北、辽宁、湖北的新录取最低分使用各省 **2026 年** 官方一分一段表对应累计人数，含义是同分考生的位次上限，不能当作精确个人排名。
- 湖北专业组线只表示该组的投档门槛，不能替代组内每个专业的录取线；源表没有组内专业清单，关键词只能匹配已经取得的专业或专业组名称。14 条华北水利水电大学记录则是学校公布的具体专业最低分和位次。
- 重庆本轮未可靠获取 2026 年原始附件，保留已核验的 2025 年官方数据。其余省份也未完成 2026 年全覆盖，现有掌上高考记录主要为 **2025 年**，保留逐校来源地址和 SHA-256。
- 历史数据仍有已知局限：新疆已有 365 条记录使用 2025 年最低分与公开转载的 **2024 年** 一分一段表换算；西藏已有 736 条 **2025 年** 记录采用基于 2024 年考生规模、招生计划和控制线的粗略位次模型。这两类旧记录不能视为同年官方位次，本轮没有新增这类跨年换算或模型估算记录。

掌上高考专业线同步脚本只扫描本科院校；首页院校地图同时包含本科和专科。官方表导入范围按各省来源及解析规则处理，原表记录数不等于网站可查询记录数。
